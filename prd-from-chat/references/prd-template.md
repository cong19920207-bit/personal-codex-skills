# PRD 模板与条件扩展

## 使用规则

- 基础结构适用于所有 PRD；缺少但相关的信息标记为 `⚠️ 待确认`。
- 条件扩展只在触发条件成立时加入，不创建不适用的空章节。
- 所有确定性数字、阈值、状态、接口和技术事实都要有来源。
- 一个文档只使用一个一级标题；后续章节从二级标题开始。
- 流程存在三个以上相互依赖步骤、分支或状态变化时，优先使用 Mermaid；简单流程使用编号步骤。
- 下列模板是结构契约，可以按项目语义调整标题，但不得遗漏适用的核心信息。
